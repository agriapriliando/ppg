# Nomor Peg ID, NUPTK, dan kategori wilayah tempat tinggal

Bagian Identitas & kontak memuat **Nomor Peg ID** (wajib saat pengiriman, maksimal 100 karakter) dan **NUPTK** (opsional, 16 angka jika diisi). Keduanya mempertahankan angka nol di depan. Nomor Peg ID biodata tidak mengubah Peg ID resmi pada daftar SK. Draf tetap dapat tersimpan saat Nomor Peg ID belum diisi.

Bagian Alamat memuat **Kategori Wilayah Tempat Tinggal** dengan pilihan:

- Wilayah Indonesia Bagian Barat (WIB)
- Wilayah Indonesia Bagian Tengah (WITA)
- Wilayah Indonesia Bagian Timur (WIT)

Pilihan wilayah ini opsional dan terpisah dari pilihan kecamatan, kota, dan provinsi. Tidak perlu memperbarui dataset referensi untuk menggunakan ketiga pilihan tersebut.

Semua kolom mengikuti autosave yang ada. NUPTK yang belum lengkap tetap dapat disimpan sebagai draf saat diketik; pengiriman akhir memvalidasi 16 angka. NUPTK pada biodata dan muatan draf disimpan terenkripsi. Data ikut tersimpan dalam snapshot pengiriman, detail peserta, pemeriksaan operator, cetak biodata, dan ekspor Excel. Ekspor menggunakan tipe teks untuk mempertahankan nol di depan.

Draf lama perlu dilengkapi Nomor Peg ID sebelum dikirim. Snapshot lama tidak ditambahkan nilai secara otomatis sehingga riwayat pengiriman tetap sesuai data saat dikirim.

Acuan format NUPTK: [Tanya Jawab Kendala Seputar NUPTK — Kemendikdasmen](https://pusatinformasi.ult.kemendikdasmen.go.id/hc/id/articles/48701890089625-Tanya-Jawab-Kendala-Seputar-NUPTK).
