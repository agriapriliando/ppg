## 📌 Ketentuan Umum Aplikasi
- **Basis Data**: Berbasis Surat Keputusan (SK) resmi penetapan mahasiswa PPG Dalam Jabatan dari Kementerian Agama RI / Ditjen Bimas Kristen.
- **Standar Waktu**: Seluruh operasional, jadwal gelombang, batas perbaikan, dan layanan menggunakan **Waktu Indonesia Barat (WIB / Asia/Jakarta, UTC+7)**.
- **Portal Akses**:
  - Halaman Beranda Publik: `http://ppg.test/`
  - Halaman Pendaftaran Akun Baru: `http://ppg.test/klaim-whatsapp`
  - Halaman Masuk Akun: `http://ppg.test/masuk`
  - Halaman Ruang Kerja / Dashboard: `http://ppg.test/ruang-kerja`
